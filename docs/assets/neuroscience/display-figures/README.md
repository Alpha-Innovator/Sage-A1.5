# Report display panels C and F

These PNGs are 300 dpi exports of the retained report PDF (revision 3), based
on the saved V3 / A1.5-Preview-local02 run. The gallery, enlarged figures and
downloads publish only these report versions of C and F. The other nine gallery
figures retain the V3 outputs. Research originals remain archived separately.

C uses the same 5,000 permutations with 0.5 percentage-point bins and a 0–1,000
count axis. F uses saved Swanson geometry and regional PC1 scores, mapped to
report blue with −4 to +8 limits. No statistical results have changed.
`provenance.json` records the PDF, export rectangles, data and image checksums.
