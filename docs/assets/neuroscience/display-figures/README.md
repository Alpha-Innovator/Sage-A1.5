# Report display panels C and F

These PNGs are 300 dpi exports of the left and right halves of the retained
report PDF (revision 3). The source is the saved V3 / A1.5-Preview-local02 run.
The gallery shows these report panels by default, with an original-image action.
The immutable original eleven images remain in `../figures/`.

C uses the same 5,000 saved permutations, with 0.5 percentage-point bins and a
0–1,000 count axis. Original C used 39 bins spanning variance fractions 0–1
and included a count-scaled KDE. Observed variance, null mean and p are unchanged.
F uses the saved Swanson geometry and regional PC1 scores, remapped to report
blue with the same −4 to +8 limits. Original rank labels remain in original F.
`provenance.json` records the PDF, export rectangles, data and image checksums.
